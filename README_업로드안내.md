# 피망머니상 새 디자인 + SEO 적용본

## 변경 사항
- 기존 빌더형 레이아웃을 제거하고, 다크 에디토리얼 히어로·밝은 정보 섹션·FAQ로 구성한 신규 랜딩페이지입니다.
- SEO 메타데이터, Open Graph, JSON-LD, robots.txt, sitemap.xml, favicon, 모바일 반응형을 포함합니다.
- 전화·카카오톡 플로팅 버튼은 표시 전용이며, 현재 번호·외부 링크는 연결하지 않았습니다.
- 플로팅 버튼은 미리보기 하단의 플랫폼 표시 위에 배치되도록 하단에서 76px 띄워 둡니다.

## 업로드 방법
이 폴더 내부의 모든 파일과 폴더를 웹사이트 문서 루트에 그대로 업로드하세요.

> 현재 canonical/OG/sitemap의 기준 도메인은 `https://jmf858g.dothome.co.kr/`입니다. 실제 대표 도메인이 다르면 `index.html`, `robots.txt`, `sitemap.xml`의 해당 URL을 함께 변경하세요.
